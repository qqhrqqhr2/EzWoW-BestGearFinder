# EzWoW-BestGearFinder

## English

**Gear recommendations and item lookup** for WoW Forever (Interface 16001).

- Install the `EzWoW-BestGearFinder` addon folder under `Interface/AddOns/`.
- The complete source distribution includes features, settings, changelog and license information.
- In-game compatibility still requires testing.

## 한국어

WoW Forever(Interface 16001)용 **장비 추천 및 아이템 획득처 검색** 애드온입니다.

- `EzWoW-BestGearFinder` 폴더를 `Interface/AddOns/`에 설치하세요.
- 전체 소스 패키지에 기능 설명, 설정, 변경 이력 및 라이선스가 포함되어 있습니다.
